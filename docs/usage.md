# 操作與資料說明

## 建議體驗順序

1. 在快速查詢輸入 `10`、`20`、`90`，查看可用長方體、加工餘量與尺寸立體圖。切換圓條時，依序填直徑與長度。
2. 查看材料總表，依供應商、月份與材料篩選；點明細回到原始單據。
3. 上傳單據頁已有四份待確認範例，可修改欄位、儲存草稿、逐筆確認，全部核對完才寫入總表。
4. 在單據範本下載虛構 JPEG，再上傳體驗實際辨識。預載原檔若已存在，會去重並開啟原紀錄。
5. 查看待分類池與垃圾桶，練習移入材料、分類與還原。
6. 在行情與價格分析觀察 S50C 或鋁材、選取 2–4 筆並排比較，或查看三筆虛構詢價。
7. 資料設定可手動更新行情、調整理論密度或預覽 CSV 匯入。

## OCR 與核對

- 第一次辨識時載入繁體中文／英文模型，速度依裝置而異；請等佇列完成再核對。
- PDF 逐頁轉圖並辨識；頁次選單可切換原圖。不同供應商或不同單據請分開上傳。
- 供應商、尺寸、日期與金額無法確定時會提示人工核對，不以紙色作為唯一判斷。
- 草稿保存成功才顯示已保存；空間不足或保存失敗時保留欄位，釋放空間後再重試。
- 「未列」與數字零分開保存。客供料的數量合計不是價款；加工費以整筆加計。
- 價格分析目前支援 S50C、6061、7075，其餘材料仍可保存、查詢及核對。

## 備份與還原

使用「下載完整備份」保存目前瀏覽器的帳本與原檔。還原只接受此 Demo 版本匯出的備份，並會要求確認。

將公開 Demo 的備份還原到本地版，可搬移原有內容；它們不會自動同步。清除網站資料或變更連接埠前，請先備份。

ZIP 備份可能包含你自行選擇的原始文件。請妥善保存，不要附在公開的 GitHub 討論中。

## 常見問題

**啟動說找不到 Node.js／npm？** 安裝 Node.js 22.13 以上並重新開啟終端機；在含有 package.json 的專案目錄執行指令。

**模型下載失敗？** 確認能存取 npm registry 與 jsDelivr，重新執行 `npm start`。模型不需 OCR API 金鑰，校驗失敗的下載不會覆蓋有效檔案。

**開了另一個分頁卻被阻止？** 同一瀏覽器的帳本一次只允許一個操作分頁，先關閉另一個 Demo 操作分頁，再重新載入。

**換網址後帳本變空？** 確認網址、瀏覽器與連接埠一致。本機預設為 `http://127.0.0.1:4173`，不要混用 localhost。

**離線時可以使用嗎？** 安裝並準備完所有資產後，讓本機服務持續執行，即可使用核心功能；行情更新需連網，失敗時保留原快取。

**可以從手機或其他電腦連進來嗎？** 本版只綁定本機 127.0.0.1，沒有區域網路部署設定。瀏覽器儲存、Worker 與分頁鎖需要適合的安全來源環境。
