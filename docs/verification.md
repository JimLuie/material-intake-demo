自動檢查以 [GitHub Actions](https://github.com/JimLuie/material-intake-demo/actions/workflows/ci.yml) 的實際結果為準。支援目標為 Windows、macOS、Linux 的 Node.js 22.13 以上。

## 自動驗證

- 原有 Python 計價、稅額、查詢、核對與分析回歸。
- JavaScript 工作台回歸、本機 HTTP 路徑與 MIME、代理來源限制、模型校驗及下載失敗重試。
- 原生 Python／Pyodide 對 31 份單據與 42 筆材料的運算、失敗回復與備份還原比對。
- 限制子程序 PATH，驗證沒有 Python 仍可打包計算核心及啟動。
- 公開來源、虛構素材雜湊、私有設定與常見憑證檔案檢查。

完整 31 份單據的備份還原另有 Python／WebAssembly 自動比對。首次以乾淨目錄執行 `npm ci`、下載模型與啟動均成功，限制 PATH 後的日常啟動不需要 Python。已由公開網址全新 clone，確認程式、鎖定檔及 README 圖片可下載。

Safari 與 Edge 尚未完成這一版本的本地人工操作矩陣。作業系統 CI 與前一版公開 Demo 的結果，都不替代這項瀏覽器驗收。

## 已知限制

- OCR 準確度與速度依裝置和文件而異，供應商與欄位可能需要人工補填。
- Edge 尚無完整人工驗收紀錄；作業系統 CI 也不等於所有瀏覽器的完整操作矩陣。
- 價格分析限既有支援牌號；外部行情可能延遲或失效，瀏覽器保留先前快取。
- 本地儲存不是跨裝置同步；請保留完整備份。
